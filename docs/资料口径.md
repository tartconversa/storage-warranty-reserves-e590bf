# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

故障实体为 incident_id，同实体多个报案 report_id 不增加独立故障。cases 中后续 revision 替代此前案件判断，只在 available_at 后可用；status 的 pending、approved、denied、appeal 表示待核、已核、拒赔、申诉。费用均为元；payments 是实际现金，不是预计赔款。合同coverage字段component限定承保部件，cap为每独立故障赔付上限，deductible为客户自付。cash_due 是批准赔款预计付款日期，拒赔仍可有已付后追偿记录。investigation 的 targeted 不代表随机样本，probability仅random适用。预防更换使旧件暴露结束，新件按replacement生效重新开始。

## units
在保设备与合同。

记录键：['unit_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| unit_id | string | 设备 |
| batch_id | string | 制造批 |
| station_id | string | 站 |
| contract_id | string | 合同 |
| commissioned | date | 投运 |
| warranty_end | date | 保障结束 |

## coverage
内部明确赔付口径，并非会计准则。

记录键：['contract_id', 'component']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contract_id | string | 合同 |
| component | string | 承保部件 |
| cap | number | 每故障赔付上限 |
| deductible | number | 每故障客户自付 |

## spells
原件与更换件暴露。

记录键：['spell_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| spell_id | string | 经历 |
| unit_id | string | 设备 |
| component_generation | string | 部件代际 |
| start | date | 开始 |
| end | date | 结束 |
| end_reason | string | 终止原因 |
| available_at | datetime | 可知时点 |

## monthly_exposure
逐月当时可知的保障暴露，不用期末全量经历倒填历史。

记录键：['unit_id', 'month_start']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| unit_id | string | 设备 |
| month_start | date | 月起日 |
| component_generation | string | 代际 |
| covered_days | integer | 承保天数 |
| available_at | datetime | 可知 |

## cases
报案版本，实体故障可有重复报案。

记录键：['report_id', 'revision']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| report_id | string | 报案 |
| revision | integer | 修订 |
| incident_id | string | 实体故障 |
| unit_id | string | 设备 |
| failed_at | datetime | 故障日 |
| reported_at | datetime | 报案日 |
| component | string | 部件 |
| status | string | 核定状态 |
| gross_cost | number | 费用预估 |
| cash_due | datetime | 预计支付日 |
| available_at | datetime | 版本可知 |

## payments
独立实际现金。

记录键：['payment_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| payment_id | string | 现金 |
| incident_id | string | 故障 |
| amount | number | 现金金额 |
| occurred_at | datetime | 发生 |
| kind | string | payment或recovery |

## investigations
实质调查结果。

记录键：['investigation_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| investigation_id | string | 调查 |
| unit_id | string | 设备 |
| incident_id | string | 故障可空 |
| selection | string | random或targeted |
| probability | number | 随机概率 |
| finding | string | 核实发现 |
| cost | number | 费用 |
| available_at | datetime | 可知时点 |

## actions

记录键：['action_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| action_id | string | 措施 |
| batch_id | string | 批次 |
| replacement_cost | number | 单台更换费 |
| days_offline | number | 停运天数 |
| new_generation | string | 代际 |

## funding
未来季度可用现金与内部缺口容忍。

记录键：['quarter']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| quarter | string | 季度 |
| start | date | 起日 |
| end | date | 止日 |
| available_cash | number | 可用现金 |
| shortfall_probability_limit | number | 缺口概率上限 |
| investigation_budget | number | 调查预算 |
